**[▶ Живое демо](https://githubuseradmin.github.io/portfolio/)**

Одностраничное персональное портфолио для самоучки-универсала в IT
(сети · безопасность · низкий уровень · DevOps) в тёмной эстетике
терминала / хакерского / сетевого стиля и с опциональной светлой темой.
Ноль зависимостей и никакой сборки — готовый шаблон, чтобы форкнуть быстрое,
доступное портфолио на GitHub Pages.

Это **чистый HTML, CSS и JavaScript** — без сборки, без фреймворков, без
зависимостей во время выполнения (один необязательный Google-шрифт). Просто
статические файлы, которые можно открыть в браузере или выложить на любой
статический хостинг. Сайт сделан mobile-first, доступен (a11y) и без проблем
разворачивается на GitHub Pages.

## Возможности

- **Переключатель светлой / тёмной темы** — кнопка в навигации меняет палитру
  и запоминает выбор в `localStorage`. При первом визите тема следует за
  системной настройкой `prefers-color-scheme`. Крошечный встроенный скрипт
  применяет тему **до первой отрисовки**, поэтому нет мигания неправильными
  цветами.
- **Подсветка активного раздела** — ссылка в навигации для раздела, который вы
  сейчас читаете, подсвечивается (`aria-current="page"`) и обновляется при
  прокрутке.
- **Печатающаяся заставка** в псевдо-терминальном «герое» (декоративно;
  настоящий, читаемый скринридером слоган присутствует в разметке).
- **Появление при прокрутке** для разделов через `IntersectionObserver`.
- **Автообновление года в подвале** — не нужно править вручную каждый январь.
- **Доступность по умолчанию** — семантические ориентиры, ссылка «к
  содержимому», видимые кольца фокуса, подписанные элементы управления и полная
  поддержка `prefers-reduced-motion`.
- **Ноль ошибок в консоли** и отсутствие блокирующего отрисовку JavaScript.

Каждое улучшение прогрессивно: с отключённым JavaScript страница по-прежнему
читается нормально, а при запросе уменьшенной анимации анимации и плавная
прокрутка отключаются, и содержимое показывается сразу.

## Запуск локально

Для просмотра инструменты не нужны. Либо:

- Дважды кликните по `index.html`, чтобы открыть его прямо в браузере, **либо**
- Раздайте папку (рекомендуется, чтобы относительные пути вели себя точно так
  же, как в продакшене):

```bash
# Python 3
python -m http.server 8000
# затем откройте http://localhost:8000
```

```bash
# Node (если установлен)
npx serve .
```

## Тесты

Чистая логика без DOM, которая решает, какую тему применить (`resolveTheme`,
`nextTheme`), покрыта юнит-тестами на **встроенном раннере Node** — никаких
зависимостей устанавливать не нужно.

```bash
node --test
# или:
npm test
```

Пример вывода:

```text
✔ THEMES exposes the two expected values
✔ resolveTheme: a saved valid choice always wins over OS preference
✔ resolveTheme: with no saved choice, OS preference decides
✔ resolveTheme: an invalid/garbage saved value is ignored
✔ resolveTheme: defaults to dark when nothing else applies
✔ nextTheme: flips between the two themes
✔ nextTheme: an unknown current state toggles to light first
✔ resolveTheme + nextTheme compose: toggling from a resolved value
ℹ tests 8
ℹ pass 8
ℹ fail 0
```

Можно также проверить синтаксис скриптов, ничего не запуская:

```bash
node --check app.js
node --check test/app.test.js
# или: npm run check
```

## Кастомизация

Всё, что вам реально захочется изменить, — это обычный текст в двух файлах.

### Имя, ссылки и текст — `index.html`

- **Имя пользователя / URL GitHub:** найдите и замените `githubuseradmin` и
  `https://github.com/githubuseradmin`. Он встречается в навигации, кнопках
  героя, ссылках каждой карточки проекта и в подвале.
- **Заголовок и слоган героя:** правьте `.hero__title` и `.hero__tagline`.
- **Фразы печатающейся машинки:** правьте массив `phrases` внутри
  `initTypewriter` в `app.js`.
- **Текст About:** раздел `#about`.
- **Навыки:** добавляйте/удаляйте элементы `<li class="chip">…</li>` внутри трёх
  блоков `.skills__group`. Используйте `chip--core` / `chip--drawn` для
  акцентных цветов.
- **Проекты:** скопируйте блок `<li class="card">…</li>`. Обновите заголовок,
  описание, элементы `.tag` и `href` ссылок. Для живого демо добавьте вторую
  `.card__link` (шаблон — в карточке `https-explained`).

### Цвета и тема — `style.css`

Палитра живёт в блоках токенов в начале `style.css`:

- `:root` хранит **структурные** токены (шрифты, радиусы, отступы, анимация).
- `:root, :root[data-theme="dark"]` хранит **тёмную** палитру (по умолчанию).
- `:root[data-theme="light"]` хранит **светлую** палитру.

Поменяйте `--accent` (зелёный) и `--accent-2` (циан) — и остальной интерфейс
подстроится. Токен `--on-accent` — это цвет текста поверх акцентных заливок,
чтобы контраст оставался корректным в обеих темах.

## Деплой на GitHub Pages

Поскольку `index.html` лежит в корне репозитория, деплой сводится к следующему:

1. Создайте репозиторий (для пользовательского сайта назовите его
   `githubuseradmin.github.io`; для проектного подойдёт любое имя) и запушьте
   эти файлы в него.
2. На GitHub: **Settings → Pages**.
3. В разделе **Build and deployment** установите **Source** в *Deploy from a
   branch*, выберите ветку (например, `main`) и папку `/ (root)`, затем
   нажмите **Save**.
4. Подождите минуту; ваш сайт появится по адресу:
   - `https://githubuseradmin.github.io/` (пользовательский сайт), или
   - `https://githubuseradmin.github.io/<repo>/` (проектный сайт).

Файл workflow не нужен — это обычные статические ресурсы. Папка `test/` и
`package.json` безвредны на Pages (они просто не отдаются как часть страницы) и
существуют только для локального тестирования.

## Заметки о доступности и производительности

- Семантические ориентиры (`header`, `main`, `nav`, `section`, `footer`),
  единственный `<h1>`, ссылка «к содержимому», `aria-label` на иконочных и
  сгруппированных элементах управления и видимые кольца `:focus-visible`.
- Переключатель темы сообщает своё состояние через `aria-pressed` и обновляет
  свой `aria-label` («Switch to light/dark theme»).
- `prefers-reduced-motion` полностью соблюдается.
- Нет блокирующего отрисовку JS (`defer`), нет внешних скриптов, кроме одного
  необязательного шрифта, который деградирует до локального моноширинного
  набора.
